Sobre este registo

Este site é um modelo pessoal para organizar resultados de natação pura e águas abertas. Os resultados iniciais são exemplos demonstrativos, não resultados oficiais. Substitui-os pelos teus dados reais antes de partilhar.

Os resultados adicionados ficam guardados neste navegador. Usa “Exportar CSV” para guardar uma cópia.
